# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working
with code in this repository.

## Overview

**nlmixr2save** saves ‘nlmixr2’ fits in a portable format (a `.zip` of
CSV files plus deparsed R scripts and a loader script) that can be read
outside nlmixr2 and independently of the package version. It also
provides the `:=` caching operator, which saves the result of an
expensive fit or simulation to disk and reloads it when the inputs have
not changed. The package is mostly R (`R/save.R`) with one small Rcpp
helper in `src/`.

Imports: checkmate, cli, digest, Rcpp, rxode2, zip. nlmixr2est,
nlmixr2data, data.table, withr, babelmixr2, PopED, tidyvpc, dplyr are
Suggests only – guard their use with
[`requireNamespace()`](https://rdrr.io/r/base/ns-load.html) /
`skip_if_not_installed()`.

## Build and Development Commands

### Install / Document

``` r

devtools::document()
devtools::install()
# or from the shell: R CMD INSTALL .
```

After changing the `// [[Rcpp::export]]` function in
`src/nlmixr2fix.cpp` (or its arguments), run
`Rcpp::compileAttributes(".")` to regenerate `src/RcppExports.cpp` and
`R/RcppExports.R`; registration is automatic
(`useDynLib(nlmixr2save, .registration = TRUE)`), there is no manual
`init.c`.

### Run All Tests

``` sh
NOT_CRAN=true Rscript -e "devtools::test()"
```

### Run a Single Test File

``` sh
NOT_CRAN=true Rscript -e "devtools::test(filter='save')"
NOT_CRAN=true Rscript -e "devtools::test(filter='simplify')"
```

Many tests fit real models and need nlmixr2est and nlmixr2data
installed; they skip otherwise.

### R CMD Check

``` r

devtools::check()
# Or: R CMD build . && R CMD check nlmixr2save_*.tar.gz
```

## Architecture

### Saving and loading fits (`R/save.R`)

- [`saveFit()`](reference/saveFit.md) is an S3 generic
  (`saveFit.nlmixr2FitCore`, `saveFit.nlmixr2FitData`, `saveFit.default`
  which errors). Each fit item is written by the
  [`saveFitItem()`](reference/saveFitItem.md) S3 generic (methods for
  `rxUi`, `data.frame`, `saemFit`, `foceiModelList`, `saemModelList`,
  `nlmixr2estSessionInfo`, `default`). Data frames go to CSV; other
  objects are deparsed to R code (`.saveDeparse()`).
- Files are named `<file>-<item>...`, plus a `<file>-env.R` and a loader
  script `<file>.R` generated by `.nlmixr2saveLoaderText()`. The loader
  restores the fit; items in `.saveFitEnv$lazy` (`foceiModel`,
  `saemModel`, `ui`) are built on first use with
  [`delayedAssign()`](https://rdrr.io/r/base/delayedAssign.html).
- [`saveFit()`](reference/saveFit.md) writes every file into a private
  temporary directory (`.nlmixr2saveFitStaged()`) and then zips (or with
  `zip=FALSE` copies) only those files. Never select files in the target
  directory by a name pattern such as `<file>-*`: `-` is legal in a base
  name, so this would sweep in another fit’s files (NEWS 0.2.1, \#10).
- `file` may include a directory; files inside the archive always use
  the bare base name so the `.zip` can be moved and loaded from
  anywhere.
- [`loadFit()`](reference/loadFit.md) accepts a base name, a bare
  symbol, or a `.zip`/`.R` path. Archives are extracted flat into a
  temporary directory, never the working directory. Loaders from older
  versions that reference a saved path are detected and regenerated
  (`.nlmixr2saveLoaderUsable()`, `.nlmixr2saveFindLoader()`). Keep
  loading of fits saved by earlier versions working.
- Version metadata (nlmixr2est/rxode2 versions and remote sha) is stored
  with a fit; [`loadFit()`](reference/loadFit.md) warns on mismatch
  unless `nlmixr2save.checkVersion` is `FALSE`.
- Type restoration after the CSV round-trip:
  `.nlmixr2saveRestoreIdFactor()`, `.nlmixr2saveRestoreIniDf0()`,
  `.nlmixr2saveRestoreParHistType()`, and the C++
  [`nlmixr2saveParFixedDf()`](reference/nlmixr2saveParFixedDf.md)
  (`src/nlmixr2fix.cpp`), which restores numeric `parFixedDf` columns as
  named or unnamed vectors depending on the nlmixr2est version that
  produced the fit.
- [`nlmixr2saveShare()`](reference/nlmixr2saveShare.md) writes
  `<name>-noData.zip` (or `<name>-noData-noFit.zip` with `noFit=TRUE`)
  without the original data.

### The `:=` cache operator (`R/save.R`)

- `:=` is an exported S3 generic; methods include `:=.default`,
  `:=.nlmixr2FitCore`, and the `assign_*` classes (`assign_nlmixr`,
  `assign_nlmixr2`, `assign_nlmixr2FitData`, `assign_default`).
- Fits are cached as `<prefix><name>.zip`; other values as
  `<prefix><name>.rds` holding the value and a sha1 digest of the call
  arguments (`.digest()`, using the digest package). A mismatched digest
  removes the cache and re-runs.
- Functions in the random registry
  ([`saveFitRandom()`](reference/saveFitRandom.md); defaults `rxSolve`,
  `simulate`, `sim`, `mrgsim`, `predict`, `vpcSim`) also store the
  rxode2 RNG seed before and after, and restore it on reload so the
  random state matches a real run.
- [`.nlmixr2saveProps()`](reference/dot-nlmixr2saveProps.md) (exported,
  internal) computes the properties of an nlmixr2 call used for the
  cache key, including the simplified data from
  [`nlmixrDataSimplify()`](reference/nlmixrDataSimplify.md)
  (`R/simplify.R`).
- [`nlmixr2saveInvalidate()`](reference/nlmixr2saveInvalidate.md)
  deletes cache files matching the current prefix in the current cache
  directory.

### Options

| Option | Default | Effect |
|----|----|----|
| `nlmixr2save.quiet` | `FALSE` | suppress `cli` info messages (`.minfo()`) |
| `nlmixr2save.dir` | `"."` | directory for `:=` cache files |
| `nlmixr2save.prefix` | `""` | prefix for cache file names; may name a subdirectory |
| `nlmixr2save.check` | `TRUE` | `FALSE` trusts an existing cache without checking inputs |
| `nlmixr2save.checkVersion` | `TRUE` | warn on nlmixr2est/rxode2 version mismatch at load |
| `nlmixr2save.data` | `TRUE` | default for `saveFit(data=)` |

### data.table attach hook (`R/zzz.R`)

data.table exports its own `:=`, which masks nlmixr2save’s when
data.table is attached later. `.onLoad` registers a single
`packageEvent("data.table", "attach")` hook that re-attaches nlmixr2save
in front of data.table (`.nlmixr2saveReattach()`), respecting
`include.only` and strict `conflicts.policy`. Tests in
`tests/testthat/test-datatable.R` run in a child R session and only run
against the installed build.

### Important Files

## Testing Conventions

- testthat edition 3; files are `tests/testthat/test-*.R`.
- `tests/testthat.R` caps rxode2/OpenMP threads to 1 when `NOT_CRAN` is
  not `"true"` (avoids the CRAN “CPU time \> elapsed time” NOTE). Keep
  it.
- Tests set `options(nlmixr2save.quiet = TRUE)`; write files inside
  [`withr::with_tempdir()`](https://withr.r-lib.org/reference/with_tempfile.html)
  (or `withr::local_*`) so nothing is left in the test directory.
- Use `skip_if_not_installed()` for any Suggests package and
  `skip_on_cran()` for slow or child-process tests.
- `tests/testthat/helper-fitfiles.R` lists the loose files of a fake fit
  written by hand in tests.

## Code Style

- Exported functions: `camelCase` (`saveFit`, `loadFit`,
  `nlmixr2saveShare`). Internal functions and local variables: leading
  dot `.camelCase` (`.nlmixr2saveBase`, `.ret`). S3 methods:
  `generic.class`.
- Validate arguments with `checkmate`; report errors with
  `stop(..., call.=FALSE)` and info messages through `.minfo()`.
- Do not use `pkg:::fun`; tests run in the package namespace and can
  call internals by bare name.
- Document exported functions with roxygen (`@param`, `@return`,
  `@export`); examples that fit models go in `\donttest{}` guarded by
  [`requireNamespace()`](https://rdrr.io/r/base/ns-load.html) and run in
  [`withr::with_tempdir()`](https://withr.r-lib.org/reference/with_tempfile.html).
- `NEWS.md` is organized per version (`# nlmixr2save X.Y.Z`) with
  past-tense bullets describing the user-visible effect.
- ASCII only in R, C++, tests, docs, vignettes, and NEWS (CRAN
  requirement): use `--`, `->`, straight quotes, `...`.

## Release / CRAN Cautions

- The package is on CRAN; `cran-comments.md` records submission notes.
- Saved archives are an on-disk format: changes to file names, the
  loader script, or item encoding must still load fits written by
  earlier versions.
- Do not write into the user’s working directory or home directory from
  examples, tests, or vignettes; use a temporary directory.
- CI: `.github/workflows/R-CMD-check.yaml` (macOS, Windows, Ubuntu
  devel/release/oldrel-1, installing nlmixr2 dependencies from GitHub),
  `test-coverage.yaml`, `pkgdown.yaml`.

## CRAN tests: never assert on timing

- Never put a wall-clock timing expectation in a test that can run on
  CRAN: no `expect_lt()`/`expect_true()` on
  [`Sys.time()`](https://rdrr.io/r/base/Sys.time.html) differences,
  [`system.time()`](https://rdrr.io/r/base/system.time.html),
  [`proc.time()`](https://rdrr.io/r/base/proc.time.html),
  `bench`/`microbenchmark` results, or any other elapsed-time threshold.
  CRAN check machines are shared and heavily loaded, so elapsed time
  there is random and a timing assertion fails at random. Example:
  nlmixr2plot `test-model-diagram.R` asserted a `modelGraph()` call took
  \< 30 s; on CRAN it took 48.4 s and failed.
- Test the result, not the speed. If a speed regression guard is really
  needed, put it only in a test that starts with `skip_on_cran()` (or
  the package’s own CRAN skip helper), and never in examples or
  vignettes.
- Tests that take more than a few seconds should also skip on CRAN.
