# This gets the estimation method for nlmixr2;

This is used to determine if this is a simulation method like `rxSolve`

## Usage

``` r
.nlmixr2saveEst(object, data, est = NULL, ...)
```

## Arguments

- object:

  Fitted object or function specifying the model.

- data:

  nlmixr data

- est:

  estimation method (all methods are shown by \`nlmixr2AllEst()\`).
  Methods can be added for other tools

- ...:

  additional arguments for nlmixr2 but ignored for this call.

## Value

estimation method
